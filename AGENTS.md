
# Rules for any AI working in this repo

1. Before any change, read docs/PRODUCT.md, docs/DESIGN.md, docs/DATA_MODEL.md and docs/MODULES.md.
2. Follow docs/DESIGN.md exactly. Never introduce new colours, fonts or spacing values. Use design tokens only.
3. Work only on the module you were asked to work on. Do not touch unrelated files.
4. No secrets in the repo. Use environment variables and update .env.example when you add one.
5. Use realistic Indian data and real copy. No lorem ipsum, no emoji as icons.
6. Make small commits with clear messages.
7. When finished, update docs/PROGRESS.md: what is done, what is mocked, what is next.
